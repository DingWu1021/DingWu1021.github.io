The research question

Seeing is only
the beginning.

Long searches demand more than a correct first impression. An agent must organize, connect, and use visual information as objects, candidates, and search targets change.

Visual context management

Keep the evidence connected.

A visual observation must stay linked to the right object, the right source, and the right next step.

◉Visual evidenceAppearance · local details · layout
→
⌘Connected contextObjects · facts · candidates
→
◎The next searchCompare · filter · follow · verify
01 / COVERAGE

Find every required item.

A convincing partial list can still miss the task. The agent must inspect the complete candidate set and preserve object-level associations.

02 / CONTINUITY

Carry the right context forward.

An earlier visual decision can define later searches. A wrong identity or lost constraint can redirect the entire chain.

03 / VERIFICATION

Return to the visual evidence.

Textual matches are not enough when the answer depends on a local detail, a spatial relation, or an exact visual identity.

A few useful details.

What makes these tasks visually grounded?

Critical decisions depend on visual evidence: object appearance, local details, candidate comparisons, or image structure. Construction checks are designed to reject tasks that can bypass these requirements through text-only shortcuts.

Why do some tasks have no initial image?

They begin with a text instruction that defines what to search. The agent still needs to find and inspect images during the search. There are 17 such tasks in the 204-task release.

How are the evaluated settings different?

Direct Answer uses the question and initial images without external tools. ReAct and DeerFlow are agent frameworks evaluated with selected model backbones. The paper reports only the model–setting combinations actually evaluated. See the paper for each framework’s tools and budgets.
